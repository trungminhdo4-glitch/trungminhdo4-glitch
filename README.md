### rufus — Trung Minh Do

Berlin. I build small local-first tools and fix bugs upstream. Most of my
time goes into systems work: process isolation on Windows, file-format
research, and keeping long-running agent tooling honest about what it
actually verified. I use AI tools while working; I read, test and can
explain every change I ship.

**Selected projects**

- [mmap-chunker-core](https://github.com/trungminhdo4-glitch/mmap-chunker-core) — Rust, splits large files into record-aligned byte ranges over a stable C ABI; on [PyPI](https://pypi.org/project/mmap-chunker-core/) and [crates.io](https://crates.io/crates/mmap-chunker-core)
- [coreguard](https://github.com/trungminhdo4-glitch/coreguard) — starts Windows processes inside a Job Object before they run, enforces limits, reports results as JSON
- [winspawn-conformance](https://github.com/trungminhdo4-glitch/winspawn-conformance) — measures what a Windows child process actually receives (argv, cwd) versus what the parent sent
- [aethelgard](https://github.com/trungminhdo4-glitch/aethelgard) — local-first triage of security / NIS-2 evidence into JSON and Markdown reports
